# 抖音推广脚本 · 键盘小达人

> 定位：亲子编程教育 + vibe coding 双话题，目标观众是家有 6-10 岁学编程孩子的家长，以及围观"普通人用 AI 做产品"的观众。
> 形式：真人出镜口播 + 屏幕实录穿插，时长 35~45 秒。

---

## 一、口播脚本（配分镜）

| 时间 | 画面 | 口播 / 字幕 |
|---|---|---|
| 0-3s | 孩子两根食指在键盘上慢慢戳键的特写（实录或摆拍） | 「我儿子学 Python，卡的第一关居然不是语法——」 |
| 3-6s | 同上，孩子抬头看屏幕、低头找键，略显着急 | 「——是键盘。」（字幕放大定格 0.5s） |
| 6-10s | 切到爸爸视角，面对镜头 | 「图形化编程拖积木拖惯了，一敲代码就露馅，比赛限时，找键找半天。」 |
| 10-13s | 爸爸摊手 / 耸肩 | 「现成的打字网站，不是广告就是满屏英文。」 |
| 13-17s | 爸爸面对镜头，画面角落闪过 AI 对话框界面 | 「我在软件行业这么多年，却没写过一行产品代码——正好想试试 AI 编程能带来什么，干脆带着 AI，自己给他做一个。」 |
| 17-19s | 录屏：网站首页三个模式卡片 | 「就是这个小网站，键盘小达人。」 |
| 19-23s | 录屏：认识键盘，小手引导 → 按键 → 字母读音 | 「先摆好小手，按对了会读出来，全是真人语音。」 |
| 23-29s | 录屏：星球大战关卡，字母敌机下落 → 按键 → 激光击落爆炸（最爽的一段，放 2-3 次击落） | 「他最爱这关，星球大战。字母从天上掉下来，按对了就击落。」 |
| 29-33s | 录屏：练打字模式 + 通关「你真棒」语音瞬间 | 「从字母到单词到短句，全对了还有奖励语音。」 |
| 33-37s | 爸爸回到镜头前 | 「不用注册、没有广告、不收任何信息，记录只存在你自己电脑上。」 |
| 37-40s | 孩子笑着敲击键盘的画面 / 或父子击掌 | 「现在每天放学主动练十几分钟。」 |
| 40-45s | 二维码海报定格（poster-qr.png） | 「网站还会一直更新。链接放简介了，域名偶尔不稳，打不开就去 GitHub 搜仓库，或者私信我要文件。」 |

## 三、引流路径（重要）

抖音不让直接挂外链，建议三件套：

1. **主页简介**写：`练键盘网站👉公众号「键盘小达人」｜GitHub：keyboard-learning-game`（公众号是唯一能让读者一键点开链接的地方，GitHub 仓库做兜底）
2. **视频结尾**用二维码海报定格 2-3 秒，口播引导「链接放简介」
3. **评论区置顶**自己评论：`需要地址的家长，去我主页简介找～临时域名偶尔不稳，打不开可以私我拿静态文件，本地就能玩`

---

## 四、拍摄 / 剪辑要点

- **前 3 秒定生死**：孩子戳键盘的"笨拙"画面是钩子，别用精美开场
- **13-17s 的"带 AI 做网站"**：配一段 AI 对话框滚动的画面，强化"不是程序员也能做"的记忆点，这部分人群互动率很高
- **击落瞬间**是爽点，至少留 2-3 个击落镜头，可以加速 1.2x
- BGM：轻快节奏的电子乐 / 8-bit 游戏风（配合像素战机画面）
- 字幕必须全程，家长很多静音刷视频
- 竖屏 9:16 录制；录屏部分用 16:9 素材嵌进竖屏，上下加纯色底
